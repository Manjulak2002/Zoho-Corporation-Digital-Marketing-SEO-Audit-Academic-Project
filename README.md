# Zoho Corporation – Digital Marketing & SEO Audit

Academic project analyzing the digital marketing and SEO posture of Zoho Corporation's website, 
paired with a landing page design case study for a separate DTC brand concept.

> **Disclaimer:** This is an independent academic/portfolio project and is not affiliated with, 
> commissioned by, or endorsed by Zoho Corporation. All data was gathered from publicly available 
> tools and Zoho's public website as of October 2025.

## 📋 Project Overview

This presentation covers:
- A technical and on-page SEO audit of zoho.com
- Core Web Vitals and mobile performance analysis
- Organic traffic and keyword research
- Strategic digital marketing recommendations
- A landing page design case study (Scent & Ember, a fictional DTC candle brand) built in Canva

## 🛠️ Tools Used

| Purpose | Tool |
|---|---|
| SEO Audit | Rank Math SEO Analyzer |
| Page Speed / Core Web Vitals | Google PageSpeed Insights |
| Traffic & Keyword Analysis | Ahrefs |
| Landing Page Design | Canva |
| Presentation | Google Slides / PowerPoint |

## 🔍 Key Findings

- Overall SEO score: 92/100 (25 of 28 tests passed)
- Strong technical SEO foundation: schema markup, canonical tags, HTTPS, mobile-first indexing
- Organic traffic concentrated in India (53%) and the US (11%), with a long tail of smaller markets
- Top keywords are predominantly branded/navigational (e.g., "zoho mail," "zoho login")
- Mobile Core Web Vitals: LCP and FCP flagged as needing improvement per Google PageSpeed Insights

## 📈 Strategic Recommendations

1. Improve mobile Core Web Vitals (LCP/FCP)
2. Expand content beyond branded search to capture commercial-intent traffic
3. Strengthen off-page authority and social presence (LinkedIn, YouTube)
4. Optimize conversion paths and retargeting for trial sign-ups
5. Localize content for emerging international markets
